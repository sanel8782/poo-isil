# Sistema Web de Cotización y Validación de Datos (PA2)

Mini aplicación web desarrollada con **JSP (JavaServer Pages)** y ejecutada sobre **Apache Tomcat**. El sistema permite 
registrar una cotización comercial, validar datos ingresados mediante la clase `String`, realizar operaciones numéricas 
y aplicar redondeos utilizando métodos de la clase `Math`

---

## Tecnologías
- **Lenguaje:** Java (JDK 21)
- **Tecnología Web:** JSP 
- **Servidor Web:** Apache Tomcat
- **Gestor de dependencias:** Maven

---

## Instrucciones de Configuración y Ejecución

1. **Clonar el repositorio o descargar el proyecto:**
   ```bash
   git clone <url-del-repositorio>

Compilar el proyecto:
Abre la terminal en la raíz del proyecto y ejecuta:

mvn clean package

Copia el archivo generado target/SistemaCotizaciones.war dentro de la carpeta webapps/ de tu servidor Apache Tomcat.

Iniciar el servidor:
Ejecuta startup.bat (en Windows) ubicado en la carpeta bin de Tomcat.

Acceder a la aplicación:
Abre tu navegador e ingresa a:
http://localhost:8080/SistemaCotizaciones/
